# 📅 Мой Автономный Еженедельник (Версия R 1.0.0)

Умный планировщик задач, школы и тренировок с автоматическим сбросом недели в воскресенье в 23:59 и поддержкой облачных обновлений.

## Инструкция по установке (НЕ ПРОПУСКАЙТЕ НЕ ОДИН ИЗ ЭТАПОВ)

1. **Создайте отдельную пустую папку** в любом удобном месте на вашем компьютере (например, на Рабочем столе) и назовите её, например, `Еженедельник`.
2. Скачайте из этого репозитория файл `planner.hta` и положите его **строго внутрь этой созданной папки**.
3. Запустите файл `planner.hta` двойным кликом мыши.

>  **Важно! при первом запуске:** Программе потребуется интернет всего на одну секунду. (planner.hta это самостоятельная программа, интернет нужен только для важного файла) Она сама автоматически скачает из облака файл логики (`logic.js`) в вашу папку, создаст текстовую базу данных для автосохранений и откроет интерфейс. В будущем интернет не потребуется — приложение умеет работать полностью офлайн.

Для обновления приложения вам не нужно самому переустанавливать базу данных. Это сделано автоматически)
Надеюсь что эта программа будет полезна
